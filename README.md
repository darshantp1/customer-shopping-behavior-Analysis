# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes **3,900 customer purchase transactions** to understand shopping patterns, customer segments, product preferences, discounts, and subscription behavior.

## 🛠️ Tools & Technologies

* **Python** – Data cleaning, EDA & feature engineering
* **PostgreSQL** – Business and transaction analysis
* **Power BI** – Interactive dashboard and visualization

## 📊 Dataset

* **Rows:** 3,900
* **Columns:** 18
* Customer demographics, purchase details, shopping behavior, ratings, discounts, and shipping information
* **Missing values:** 37 in Review Rating

## 🔍 Analysis Performed

### Python

* Data cleaning and exploration using Pandas
* Handled missing Review Rating values
* Standardized column names
* Created age groups and purchase frequency features
* Loaded cleaned data into PostgreSQL

### SQL

Analyzed:

* Revenue by gender
* High-spending discount users
* Top-rated products
* Shipping type comparison
* Subscribers vs. non-subscribers
* Discount-dependent products
* Customer segmentation
* Top products by category
* Repeat buyers and subscriptions
* Revenue by age group

### 📈 Power BI Dashboard

Created an interactive dashboard to visualize key customer, product, revenue, discount, and subscription insights.

## 💡 Business Recommendations

* Increase subscription adoption through exclusive benefits
* Introduce loyalty programs for repeat customers
* Review discount strategies to maintain margins
* Promote top-rated and best-selling products
* Use customer and age-group insights for targeted marketing
